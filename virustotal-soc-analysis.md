# **VirusTotal Analysis for SOC Analysts**

## **Overview**

This project demonstrates my ability to use VirusTotal to investigate potential threats as a SOC analyst. The focus is on identifying indicators of compromise (IOCs), analyzing file hashes, URLs, and domains, and documenting findings in a structured manner.

## **Objectives**

* Investigate suspicious files, URLs, and domains  
* Identify potential malware or phishing indicators  
* Use VirusTotal to gather threat intelligence  
* Document findings and map to SOC workflows

## **Skills Demonstrated**

* Threat intelligence collection and analysis  
* File hash and URL investigation  
* SOC incident response methodology  
* Documentation and reporting

##  **Tools Used**

* VirusTotal

## **Key Concepts**

* Indicators of compromise (IOCs)  
* File hash reputation and analysis  
* Domain and URL reputation checks  
* Mapping alerts to SOC workflow

 **Outcome**

Successfully investigated simulated threats, identified malicious indicators, and documented structured incident reports demonstrating SOC level threat analysis.
